# Mez Media: client acquisition system

Paid social (Meta, then TikTok) for UK DTC skincare brands.

| Path | Purpose |
|---|---|
| `leads/lead_database.csv` | Every researched lead: source, score (A/B/C), status |
| `outreach/messages_queue.csv` | Drafted messages awaiting approval |
| `outreach/sent_log.csv` | Approved and sent messages, with timestamps and follow-up dates |
| `outreach/followups_due.csv` | Follow-up schedule (max 3 touches per lead) |
| `content/content_calendar.csv` | Inbound content drafts (3 shorts + 2 carousels per week) |
| `sales/call_notes.md` | Call agenda, qualification, honest objection answers, call logs |
| `sales/proposals/` | Pilot proposal template and client proposals |
| `reports/weekly_report.md` | Friday report |
| `assets/ad_teardowns/` | Teardown notes and screenshots |
| `7_day_action_plan.md` | Current week's plan |

**Message statuses:** draft → awaiting approval → approved → sent → replied → call booked → closed-won / closed-lost

**Rules:** No message, post or purchase happens without approval. No invented results, clients or testimonials. No misrepresenting who we are or where we're based.
